# リユースショップ店長

リユースショップを立ち上げた店長として、1年間お店を経営する選択肢型のノベルゲームです。遊びながら「売上・利益・在庫・固定費」といった経営の基礎が身につきます。

- ブラウザだけで動きます（ログイン・AI・外部サービスなし）
- スマホ向けの縦長画面。パソコンでもそのまま遊べます
- 1回のプレイは10〜15分ほど。結末は5種類

## ファイル

| 場所 | 中身 |
|---|---|
| `index.html` / `css/` | 画面 |
| `js/engine.js` | 計算の仕組み（売上・収支・結末・選ぶ前の見通し） |
| `js/data-big.js` | 毎月の大きな出来事 |
| `js/data-small.js` | 小さな出来事（70種類以上） |
| `js/data-text.js` | 登場人物・用語メモ・結末・経営タイプ診断 |
| `js/ui.js` | 画面の動き |
| `assets/` | イラスト |
| `tools/simulate.js` | 自動で1万回遊ばせて難しさを確かめる（`node tools/simulate.js`） |
| `SPEC.md` | 仕様書 |
